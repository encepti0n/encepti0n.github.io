Hello world — why I built this site

September 8, 2026 · 2 min read

This is the first post on my site. I built the whole thing from plain HTML, CSS and a small amount of JavaScript — no framework, no build step, nothing to install. Every page here is a file I can open and read.

That was deliberate. Static sites are the one corner of the web that still works the same way it did fifteen years ago: a folder of files, served as-is. When something looks wrong, the answer is somewhere in a file I wrote, not in a dependency tree.

How a post gets published

Adding a post takes three steps:

  1. Copy this file and rename it.
  2. Add an entry at the top of js/posts.js.
  3. Commit and push.

GitHub Pages rebuilds within about a minute. Here is what pushing looks like from the terminal: 

git add .
git commit -m "New post: hello world"
git push
The best time to start writing was when you built the site. The second best time is now.
